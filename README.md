# 熊沢建設 Q1 KPI

熊沢建設の全社予算・担当マップ・河野さん個人版KPIを表示する静的HTMLです。

## 公開前の注意

このリポジトリは公開設定を想定しています。公開すると、HTMLに記載された会社名、予算、担当者名、営業目標などを誰でも閲覧できます。内容を確認したうえで公開してください。

## Cloudflare Pages

このリポジトリをCloudflare PagesのGit連携に接続すると、`main`へのpushをきっかけに自動更新できます。静的HTMLのため、ビルドコマンドは`exit 0`、出力先は`.`で設定します。

## データ保存について

入力値とチェック状態は、利用者ごとのブラウザ内`localStorage`に保存されます。河野さんが入力した値を他の端末へ共有する仕組みは、この版には含まれていません。
